💡 Deals vs VOY:
Deals — игры с явными признаками поиска издателя (behavioral intent: "ищу издателя", "seeking funding" и т.д.). Фокус на явных сигналах о поиске издателя.
VOY — интеллектуальный скаут с разными целями (publisher_hunt, high_potential, undermarketed), использует skills для скоринга и может обучаться на основе feedback. Более гибкий поиск игр с потенциалом.

🚀 Relaunch Scout — Rebound Window Edition

Концепция: находим недореализованные игры в Rebound Window (6-24 месяца после релиза).
НЕ ищем: новые игры, тренды, хайп — это для других вкладок.
Ищем: игры, которые не выстрелили, но имеют потенциал для перезапуска.

1) Ручной Track (точечно)
Endpoint: POST /api/v1/relaunch/admin/track
Совет: priority=50 — нормальный дефолт.
2) Bulk Track (массово, как продакшн-инструмент)
Endpoint: POST /api/v1/relaunch/admin/bulk_track
Bulk режим НЕ ходит в Steam. Он выбирает кандидатов из БД (steam_games или games).
3) Сканировать рынок (Rebound Window)
Endpoint: POST /api/v1/relaunch/admin/market_scan
Rebound Window: ищет недореализованные игры 6-24 месяца после релиза (НЕ новые, НЕ тренды).
Критерии: reviews 50-5000, price > 0, не DLC/demo. Парсит Steam напрямую или использует каталог БД.
